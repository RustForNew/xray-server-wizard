# Changelog

## 0.2.3 — 2026-07-13

- Добавлена защита от циклического REALITY target: домен/IP, указывающий на этот же VPS и тот же публичный порт Xray, отклоняется прямо при вводе.
- Сетевая проверка повторяется после установки зависимостей, но до отключения Nginx, backup и изменения рабочих конфигов — это защищает также от изменения DNS между вводом и применением.
- Target на этом же VPS с другим портом не блокируется: такой вариант допустим, если на отдельном порту действительно работает подходящий TLS-сервис.
- Target по умолчанию в экспертном режиме изменён на `www.amazon.com:443`, совпадающий с первым проверяемым кандидатом автоматического режима.

## 0.2.2 — 2026-07-13

- Исправлена runtime-аутентификация VLESS и Trojan в Xray 26.3.27: credentials теперь записываются в фактически поддерживаемое поле `clients`, а не в принимаемое синтаксическим тестом, но не применяемое поле `users`.
- Добавлено ожидание блокировки `apt/dpkg`, возникающей на чистой Ubuntu из-за `unattended-upgrades`, вместо немедленного аварийного завершения.
- Временный Xray-конфиг получает суффикс `.json`, необходимый актуальному Linux-бинарнику для определения формата.
- Автоматический REALITY target переставлен на проверенный первым кандидат: успешный `xray tls ping` сам по себе не гарантирует завершение REALITY handshake.
- В экспертном XHTTP доступны все режимы `auto`, `packet-up`, `stream-up` и `stream-one`; автоматический режим использует `auto`.
- На чистом Ubuntu 22.04 VPS проверены реальный Let's Encrypt, Nginx-заглушка, Certbot dry-run и клиентский трафик VLESS+XHTTP+TLS и VLESS+TCP/RAW+REALITY.

## 0.2.1 — 2026-07-13

- Исправлено аварийное завершение автоматического режима после ввода количества UUID для всех профилей, кроме Hysteria2.
- Автоматический режим теперь сначала предлагает protocol/transport, затем отдельно REALITY или TLS для совместимых транспортов.
- TCP/RAW помечен предупреждением: обычный TCP+TLS легче классифицировать; REALITY не приравнивается к нему по блокируемости.
- Добавлены регрессионные тесты интерактивной логики автоматического режима.

## 0.2.0 — 2026-07-13

- TLS-профили теперь автоматически устанавливают Nginx и создают нейтральный адаптивный HTTPS-сайт-заглушку.
- Certbot переведён со временного standalone listener на постоянный Nginx webroot для безопасного автоматического продления.
- Добавлены отдельные TLS-топологии: Xray fallback для TCP/RAW, reverse proxy для WS/gRPC/XHTTP и общий номер TCP/UDP-порта для Hysteria2.
- Для XHTTP и gRPC Nginx использует `grpc_pass`; для WebSocket — Upgrade reverse proxy.
- Добавлены совместный backup/rollback Xray и Nginx, проверка `nginx -t`, восстановление страницы и состояний сервисов.
- Добавлена проверяемая поддержка AAAA/IPv6 в автоматическом ACME-режиме.
- UFW для TLS открывает `80/tcp` и нужные TCP/UDP-порты.
- Тесты расширены проверкой Xray 26.3.27 и Nginx 1.18.0 для всей поддерживаемой матрицы.

## 0.1.0 — 2026-07-13

- Добавлен автономный однофайловый мастер для Ubuntu 22.04.
- Добавлены автоматический и экспертный режимы.
- Поддержаны VLESS/Trojan с TCP/RAW, XHTTP, gRPC и WebSocket в допустимых TLS/REALITY-сочетаниях.
- Добавлен нативный Hysteria2 для Xray-core 26.3.27+.
- Добавлена пакетная генерация до 500 UUID и URI-ссылок в защищённый TXT-файл.
- Добавлены ACME через Let's Encrypt, существующие TLS-сертификаты, backup, `xray run -test`, systemd-проверка и откат.
- Добавлены тесты полной матрицы из 15 профилей.
