# Changelog

## 0.1.0 — 2026-07-27

- Добавлен отдельный однофайловый мастер NaïveProxy для Ubuntu 22.04 и 24.04.
- Добавлены быстрый, пошаговый и экспертный режимы.
- Добавлены HTTPS/HTTP2 и QUIC/HTTP3, ACME и существующий TLS-сертификат.
- Добавлены несколько пользователей, генерация, импорт, добавление, удаление и ротация пароля.
- Добавлены статический cover-site, reverse proxy, redirect и нейтральный 404.
- Добавлены probe resistance, секретный PAC, ACL, ограничения портов и upstream proxy hop.
- Добавлена безопасная сборка Caddy 2.11.4 с закреплённым commit naïve forwardproxy.
- Добавлены systemd hardening, UFW, config validation, authenticated CONNECT smoke и защищённый client bundle.
- Добавлены транзакционные snapshot, автоматический rollback, обнаружение незавершённой операции и config drift.
- Уточнена проверка свободного места для source build: 3 GiB обычно и 5 GiB при создании временного swap.
- Исправлены права каталога статических ресурсов cover-site при строгом `umask`.
- Атомарная запись больше не ослабляет права существующих родительских каталогов; mode корня конфигурации теперь входит в drift manifest.
- Проверка ALPN пишет вывод OpenSSL во временный защищённый файл и не передаёт NUL-байты через Bash-переменную.
